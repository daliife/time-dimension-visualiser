# time-dimension-visualiser

A WebGL view of a short clip as a stack of frames. Time runs left to right, and playback lights the current frame.

The clip is a four-second excerpt of [Sample Mp4 Videos](https://archive.org/details/SampleVideo1280x7205mb) from the Internet Archive. `public/example.mp4` is the 9gag reference: one clear frame, with the other slices transparent so pixel trails show how things move.

```bash
corepack enable
pnpm install
pnpm dev
```

GitHub Pages: https://daliife.github.io/time-dimension-visualiser/
